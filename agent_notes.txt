# Mantra Tech Voice Agent - Technical Requirements

## Core Objectives

* Handle incoming customer and lead calls.
* Answer queries using Mantra Tech knowledge base.
* Create and manage support tickets.
* Book consultation calls.
* Maintain conversational memory across calls.
* Integrate with Zoho CRM and Zoho Desk.

---

# Data Storage

## Identity Store

Maintain a unique identity per phone number.

Store:

```text
Phone Number
Name
Preferred Language
Created At
Last Call At
Agent Notes
Customer Profile Summary
```

Notes:

* A caller may simultaneously be a Lead, Customer, and Support User.
* Do not classify callers into a single type.

---

## Call Store

Store every call.

```text
Call Id
Phone Number
Timestamp
Duration
Transcript
Call Summary
Detected Intent
Call Outcome
```

---

## Customer Memory

Maintain long-term memory per identity.

Examples:

```text
Preferred Language
Common Issues
Previous Discussions
Special Notes
```

# Call Context Construction

Context Sources:

```text
Our Database
Zoho CRM
Zoho Desk
Recent Call History
```

Inject:

```text
Identity Information
Customer Memory
Last 3 Call Summaries
Open Tickets
CRM Information
Recent Timeline Events
```

Do NOT inject:

```text
Full CRM Payloads
Full Ticket Payloads
Full Transcripts
```

---

# Incoming Call Flow

```text
Incoming Call (Plivo)
        ↓
Connect WebSocket
        ↓
Create Call State
        ↓
Fetch Cached Context (Redis)
        ↓
Generate Initial Greeting
        ↓
Start STT/TTS Pipeline
```

In Parallel:

```text
Fetch Identity
Fetch CRM Context
Fetch Ticket Context
Fetch Call History
Fetch Customer Memory
```

When data arrives:

```text
Update Call State
```

On subsequent LLM turns:

```text
Automatically inject newly available context
```


# Chronological Awareness

Agent should be aware of:

```text
Last Call Time
Last Call Summary
Recent Tickets
Recent CRM Activity
Recent Bookings
```

Example:

```text
Called 1 hour ago
Ticket created yesterday
Consultation booked last week
```

The agent should use chronology naturally during conversation.

---

# No Response Handling

```text
Ask Again Once

```

```text

```

# Post Call Flow

```text
Call Ends
      ↓
Generate Transcript
      ↓
Generate Summary
      ↓
Extract Intent
      ↓
Update Customer Memory
      ↓
Store Call Record
      ↓
Create Timeline Event
```

If Unknown Caller:

```text

```

```text
Create Ticket in Zoho Desk
```

# Architecture

```text
Plivo
  ↓
Pipecat
  ↓
LangGraph Agent
  ↓

Tools

- Knowledge Base Search
- Zoho CRM
- Zoho Desk
- Booking System
- Customer Memory
- Call History
- Identity Store
```

The most important design rule:

```text
Our Database = Conversational Memory

Zoho = Business Workflow State
```

Keep those responsibilities separate.


Our primary database will be in MONGODB.
