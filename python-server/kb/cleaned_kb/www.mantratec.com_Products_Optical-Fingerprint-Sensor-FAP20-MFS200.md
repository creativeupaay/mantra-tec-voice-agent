MFS200 bridges FAP10 and FAP30 with a certified 15.24 x 20.32 mm sensing area - delivering high-performance capture in a compact desktop form factor.

Scratch-free optical sensor captures 300 x 400 pixel grayscale images from a 15.24 x 20.32 mm (0.6 x 0.8 Inch) sensing area using a RED LED light source for consistent image quality.

FBI PIV | WBF | USB-IF

### Global Certifications

FBI PIV certified image quality ensures compliance with federal ID standards. Fully compliant with ANSI 378, ISO 19794-2, CE, FCC, RoHS, and EN/IEC 62368-1. WBF driver enables seamless Windows integration.

Latent finger detection prevents spoofing. Combined with a MINEX-certified high-performing fingerprint algorithm, it offers an exceptional FRR < 0.1% and FAR < 0.001% for secure transactions.
