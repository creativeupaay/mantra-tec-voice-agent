# Introduction

Mantra Bionic8 is the most advanced fingerprint and smart card reader terminal featuring next-generation biometric technology and security platform. Bionic8 provides class-leading performance through the world’s best matching performance, uncompromised security, and accuracy along with top-notch usability.

It is a wall-mounted biometric tablet with BOSS ( Bharat operating system), featuring biometric fingerprint identification, smart card reader to provide multiple functions for various customer applications. It can be deployed in a wide variety of environmental conditions. It is specifically designed for mounting on surfaces used in indoor or outdoor places. It also has an inbuilt battery that can handle long hours of intense usage along with it has IP65 water & dustproof capability and has met the IEC sealing standards.

# Features

*   Rugged design; IP65 Sealing.
*   User Friendly design offers Intuitive User Experience; Ultrafast User Identification.
*   Ultrafast User Access and Higher Security
*   Secure eMMC boot; On board 16GB offers Higher Capacity to Manage User & Events.
*   In-built Secure Access Module; supporting ISO7816 compliant Contact Smart Card
*   Contactless Smart Card Module; supporting ISO14443 compliant Contactless Smart Card
*   Tamper Detection and Protected.
*   Battery Operated Devices with back-time of 5 hours.
*   Multi Finger Capacitive touch display with Scratch proof Gorilla Glass.
