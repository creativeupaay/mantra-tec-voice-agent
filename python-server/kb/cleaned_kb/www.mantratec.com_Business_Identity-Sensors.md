## Fast start checklist

### How to select the right biometric device.

Before choosing a fingerprint scanner, iris scanner or biometric terminal, define the environment, user volume, compliance requirement, integration path and security risk.

01. **Define the workflow**
    Separate enrollment, authentication, attendance, access control and KYC use cases before device selection.
02. **Match sensor to risk**
    Select optical, capacitive, iris or multi-modal devices based on assurance level and convenience.
03. **Check compliance needs**
    Confirm Aadhaar, FAP, STQC, operating system and project-specific requirements before procurement.
04. **Plan integration early**
    Map SDK, API, driver, encryption and application requirements before field rollout.
05. **Test field conditions**
    Validate wet fingers, sunlight, dust, outdoor use, high-volume queues and edge cases.
06. **Secure the data flow**
    Protect device communication, biometric templates, logs and access controls across the full lifecycle.
