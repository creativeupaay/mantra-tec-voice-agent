# Optical Fingerprint Scanner Model: MFS100

MFS100 is a high-quality USB fingerprint sensor for fingerprint authentication to access desktop or network security. MFS100 is based on optical sensing technology which efficiently recognizes poor quality fingerprints also. MFS100 can be used for authentication, identification and verification of an individual that let your fingerprint act like digital passwords which cannot be lost, forgotten or stolen. Hard optical sensor is resistant to scratches, impact, vibration and electrostatic shock.
