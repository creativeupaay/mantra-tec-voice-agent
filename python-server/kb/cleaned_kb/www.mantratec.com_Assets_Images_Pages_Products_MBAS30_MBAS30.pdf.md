# MBAS

## AADHAAR ENABLED BIOMETRIC ATTENDANCE SYSTEM

Fingerprint Camera In-Built WiFi 3G/4G Android

Overview

Mantra’s 7” L1 AEBAS Device MBAS30 is designed for high-precision individual identification, integrating advanced biometric algorithms with PIV/STQC L1-certified MFS110 scratch-free optical fingerprint scanner. It is ideal for applications such as aadhaar based time attendance.

The MBAS30 is wall-mounted for time attendance purposes. Its capacitive scratch-resistant touchscreen with toughened glass ensures durability, while optimized thermal management enhances performance.

With built-in 4G, Ethernet, Wi-Fi, and GPS, the MBAS30 ensures seamless connectivity. Additionally, the 6,000 mAh battery with auto sleep and wake-up functionality provides extended battery backup, making it a reliable choice for uninterrupted operations.
