## Frequently Asked Questions

Find answers to common questions about our m-Authentication (AUA/KUA) solutions.

###### What is the Mantra AUA/KUA framework?

It is a secure gateway that connects your applications with UIDAI's Central Identities Data Repository (CIDR) through dedicated network links, providing prompt and secure Aadhaar authentication services.

###### Is the m-Authentication solution compliant with UIDAI standards?

Yes. Our framework strictly adheres to the latest UIDAI specifications and protocol standards, including support for RD (Registered Devices) and Aadhaar Vault compliance using HSM-only encryption.

###### What types of authentication does the system support?

The Mantra AUA/KUA framework supports multi-modal authentication, including fingerprint, iris, and OTP-based verification, as well as demographic and photograph retrieval through E-KYC services.

###### Can this solution be integrated into existing mobile or web applications?

Absolutely. Our platform is agnostic and provides robust APIs and SDKs that allow for seamless integration into any existing mobile or web application.

###### What industries can benefit from the Aadhaar-based authentication service?

It is ideal for banks, financial institutions, government departments, and corporate entities for secure customer onboarding, premises access verification, and fraud prevention in benefit distributions.
