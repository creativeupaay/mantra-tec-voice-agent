## INDIGENOUS BIOMETRICS INNOVATION

Mobile IRIS Scanner MOBILRIS

IRI recognition is an automated method of biometrics identification that uses mathematical pattern recognition techniques on video images of one or both of the irises of an individual’s eyes. IRIS recognition is widely used for identity verification or identification for highly secured project across the world.

MobiIRIS is India’s first mobile IRIS module for mobile users. MobiIRIS is used with Mantra world class mobile enabled IRIS recognition SDK to equip any mobile phone/tablet with IRIS recognition technology.

MobiIRIS module can be integrated with any mobile platform with android operating system. This comes with 5 critical components (Sensor, Extractor, LED immolator, Lens & Images Acquisition Display & Control SW), which will be approved by UIDAI/STQC.
