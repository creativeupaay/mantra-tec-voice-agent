## Frequently Asked Questions

Below are clear answers to common questions businesses ask before deployment.

### How does biometric access control integrate with attendance and payroll?

When an employee authenticates using fingerprint or face recognition, the entry is logged instantly. That same data feeds attendance records and directly supports payroll calculations, including overtime and shift-based wages. This removes reconciliation errors and duplicate entries.

### Can the system manage multiple locations from one dashboard?

Yes. Enterprises can monitor and control access, attendance, and workforce data across all branches, plants, warehouses, or project sites through a centralized dashboard with role-based permissions.

### Is the platform suitable for manufacturing and contract labour operations?

Yes. It supports contractor onboarding, labour attendance tracking, statutory compliance documentation, wage calculation, and real-time headcount visibility. It is designed for environments where labour scale and compliance monitoring are daily requirements.

### Does the payroll module support Indian statutory compliance?

The payroll system supports PF, ESIC, TDS, overtime calculations, and multi-state salary structures. Reports are generated in compliance-ready formats to reduce audit preparation time.

### Can the solution be deployed on-premise or in private cloud?

Yes. Organizations can choose on-premise deployment for internal control or private cloud for centralized, scalable access. The system is built to maintain data security in both environments.
