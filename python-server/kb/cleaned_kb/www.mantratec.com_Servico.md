## Mantra Servico

MANTRA SERVICO is a web-based tool which is developed for customer support and it has the capability to generate and track complaints regarding the devices supplied by Mantra.

It also enables customer relation teams to monitor the total number of complaints received in particular regions to provide better support through deploying more resources in a particular region.

This application allows the customers to register complaints and helps them to track the status of the same, with regular updates via mail.
