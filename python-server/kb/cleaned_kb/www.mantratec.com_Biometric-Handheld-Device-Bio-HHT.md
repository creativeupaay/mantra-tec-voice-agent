### Hardware & System

*   **CPU**: ARM Cortex®-A7 core, 528MHz
*   **Memory**: 512MB RAM & 16GB eMMC
*   **Keypad**: 4 x 4 Matrix Keypad with Alphanumeric Keys
*   **Toughen Glass**: Scratch Resistant 6H Toughen Glass
*   **Operating System**: BOSS OS, Debian Linux
*   **Audio**: 1W, 8 Ohm Speaker for Announcements
*   **Dimensions**: 213 mm (L) x 96 mm (W) x 84 mm (H)
*   **Weight**: Approx 500 gm
*   **Operating Temperature**: 0 Deg - 60 Deg C
*   **Certifications**: CE, RoHS, BIS, IP65, Drop Test

### Fingerprint Sensor

*   **Fingerprint Type**: Scratch Free Optical Sensor
*   **Fingerprint Image**: 316 x 354 Pixels ( 16 x 18 mm )
*   **Image Specs**: 500DPI, 8 Bit Grayscale
*   **Certifications**: CE, FCC, RoHS, STQC, PIV, IEC60950

### Smart Card Reader

*   **Contactless Card**: ISO14443 Type A/B Cards, 424 Kbps, 50mm range
*   **SAM**: ISO7816 Class A

### Interfaces

*   **Ethernet**: 10/100 Mbps, Through Docking Station
*   **SAM Socket**: 1 x SAM Socket On Board
*   **DC Jack**: 1 x DC Power Input, through Docking Station
*   **Micro USB**: 4-Pin Micro USB, Through Aux Connector
*   **USB OTG**: 5 Pin On Board USB Connector

### Electrical

*   **Power Adaptor**: Input AC: 100~275V; Output DC: 5V/3.0A
*   **Battery Back-Up**: Li-Po 4000 mAH Rechargeable & Replaceable
