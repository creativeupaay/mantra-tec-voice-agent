## Core Endpoints

## Six Pillars of Facial Intelligence

Each endpoint does one job well. Combine them in sequence to build full identity verification pipelines, or call individual endpoints depending on what your application needs.

##### Face Detection

Locates all faces in an image and returns bounding box coordinates for each. Handles multiple faces in a single image, with per-face confidence scores. Minimum face size: 50x50 pixels.

##### Face Comparison

Compares two face images and returns a similarity confidence score between 0 and 1. Set your own match threshold - typically 0.75+ for KYC use cases, 0.60+ for access control.

##### Face Search (1:N)

Searches a pre-registered face database to find the closest match. Returns top-N results with confidence scores. Suited for watchlist management, access control, and attendance systems.

##### Liveness Detection

Verifies that the face in frame belongs to a live person and not a photo, screen, or 3D mask. Critical for KYC onboarding, preventing spoofing attacks, and meeting biometric compliance requirements.

##### Face Attribute Analysis

Returns per-face attribute predictions: estimated age, gender classification, emotion detection, glasses, facial hair, and mask detection. Useful for analytics, access policy enforcement, and user profiling.

##### Facial Landmarks

Returns 68-point landmark coordinates mapped to the face: eyes, nose, mouth, jaw, and eyebrows. Used for facial alignment, 3D modeling, AR overlays, and downstream face processing pipelines.
