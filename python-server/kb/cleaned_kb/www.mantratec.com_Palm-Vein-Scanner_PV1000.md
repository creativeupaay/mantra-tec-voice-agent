## Technical Details

Detailed technical specifications for PV1000 Palm Vein Terminal.

### Performance

Users Capacity: 20000 (Expandable up to 50000)
Transactions Log: 100000 (Expandable up to 1000000)
Matching Options: 1:N, 1:1 & 1:G
Matching Speed: 2 seconds for 1:1 matching
Highest Security: 1:N matching (200 users)
Medium Security: 1:G matching
Lowest Security: 1:1 matching
User Groups: 100 (0-99)

### Interface & Display

Screen: 6.5 inch color touch screen LCD
Connectivity: TCP/IP and USB pen drive
Control Panel: 18 keys keypad to operate terminal
User Indication: 5 LED

### Sensor & Camera

False Acceptance Rate: 0.00008%
False Rejection Rate: 0.01%
Camera: 2MP in built camera (optional)
Certification: CE, FCC Certified

### Hardware & Power

Power Input: DC 12V 5 Amp
Inputs: Optional 4 I/O inputs (Relay, Fire etc.)
Access Control: Feature (optional) Built-in
Voice / Buzzer
