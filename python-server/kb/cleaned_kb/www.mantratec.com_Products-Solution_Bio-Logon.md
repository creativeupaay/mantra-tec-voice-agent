# Mantra's Bio Logon

Mantra's Bio Logon is a secure and convenient biometric-based login solution, utilized to securely login into mobile applications or online portals. The next-generation biometric technology makes a login process more simplistic and secure, instead of having to enter passwords.

## How does Bio Logon Work?

Our Bio Logon solution uses fingerprint biometric authentication technique for login process in which the user proves his identity without giving any information out to the hacker.

### 01 Enrollment

This is the first step for all the users turning on biometric authentication. During enrollment, the fingerprint image is captured and stored onto the cloud server for future matching.

### 02 Authentication

The App or Web Portal prompts the user to authenticate using their fingerprint. If successful, the user gets access; otherwise, login is denied.

"Through our bio logon solution, an individual can log in into any web portal or mobile App using his/her fingerprints. The captured fingerprint image will then be sent securely onto the cloud server, which will match the user's fingerprint impression for verification."
