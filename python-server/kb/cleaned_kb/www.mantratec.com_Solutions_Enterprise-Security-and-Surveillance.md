## Frequently Asked Questions

Answers to the most common questions from enterprise security decision-makers.

### What is the difference between traditional CCTV and AI-powered surveillance?

Traditional CCTV systems passively record footage for post-incident review. AI-powered surveillance actively analyses every frame in real time - detecting faces, objects, and behaviours, flagging anomalies, and triggering alerts before incidents escalate. The result is a shift from reactive recording to proactive threat prevention, with 80% fewer false alarms compared to motion-triggered legacy systems.

### How is footage stored and who can access it?

Footage is stored on local NVRs with automatic encrypted backup to hybrid cloud. All storage uses AES-256 encryption. Access is governed by role-based permissions with full audit trails, multi-factor authentication, and an Evidence Lock feature that creates tamper-proof, legally admissible footage.

### How scalable is the platform for a large enterprise with multiple sites?

The platform is designed for enterprise scale. It supports management of thousands of cameras across hundreds of geographically distributed sites - all from a single centralised dashboard with Smart Map visualisation. Multi-tenant architecture allows parent organisations to manage subsidiaries with separate access policies.

### Does the system integrate with our access control and HR systems?

Yes. The platform offers native integration with Mantra's access control system and open API connectors for third-party access control, HRMS, alarm panels, and IoT sensor networks. This creates a unified Physical Security Operations Centre (PSOC) where video, access events, and sensor alerts are correlated.
