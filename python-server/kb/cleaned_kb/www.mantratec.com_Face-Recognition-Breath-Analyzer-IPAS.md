## Key Highlights

## Identity + Sobriety: One Unified System

IPAS-AI is the only system that links biometric identity with sobriety verification in a single interaction - ensuring that only the right person, in the right state, can access safety-critical operations.

### Precision Breath Detection

Electrochemical fuel cell sensor delivers laboratory-grade accuracy (0.005%BAC) without requiring a mouthpiece. Response time under 3 seconds.

### 2MP Wide-Dynamic Camera

Binocular dual RGB+NIR camera captures faces within 300ms from 30-150cm. Works from 0.1 LUX to direct sunlight with 100dB HDR.

### High-Performance AI Processor

Quad-core ARM Cortex-A73 with deep learning NPU drives real-time biometric and breath data processing entirely on-device.

### Access Denial

When BAC exceeds threshold, access is denied and logged against the identified user's record with a full audit trail and anti-spoofing liveness.

### Rich Network Connectivity

Full suite: 4G LTE, Wi-Fi, RJ45, HDMI, RS232/485, and Wiegand I/O for seamless integration with existing safety and access panels.

### Integrated EDHMS

Includes an integrated module for fleet and transport safety, logging health-linked access events for regulatory compliance.
